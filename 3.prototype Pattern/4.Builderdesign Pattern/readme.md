The Builder Design Pattern is a creational design pattern used to construct complex objects step by step, especially when an object has many fields, optional properties, or different configuration combinations.

Let's understand why we need it, what problem it solves, how it works, and when to use it.
1. First, understand the problem
Imagine you are developing a laptop shopping application. A laptop has these properties:
- Processor
- RAM
- Storage
- Graphics card
- Touchscreen
- Price
